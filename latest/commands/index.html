Commands

Every command wand implements today, one page each. The pages are written from the command definitions, not from memory: flags, help text and exit codes match what the binary does.

covenant and bless are not here. They are stubs — they parse and print and nothing else — and a reference page for a command that does not work yet is worse than a missing one. They get pages in the change that makes them real.

What every command shares

LINEAR_API_KEY. Everything that talks to Linear reads a full-access key from the environment, never from a file — a key in a checked-in file is a key in the repo forever. Create one in Linear’s security settings. wand ui and wand version are the exceptions; they need no key.

The covenant file. A checked-in wand.toml parameterizes the covenant — status names, caps, commands. Absent one, the stock covenant applies. init, doctor and queue read it from the working directory; the lifecycle verbs walk up from the working directory to find it, so a verb run from a subdirectory sees the same covenant as one run at the root. Run the first three from the repo root.

Exit codes. Unless a page says otherwise, a command exits 0 on success and 1 on any failure, with the reason on stderr. Three commands say otherwise, and each of their codes is a contract something else depends on: guard (the harness hook), doctor (CI), and file (a refusal to file a duplicate is a failure, on purpose).

wand init
Bootstrap a Linear team to the covenant and install the guard hook.
wand doctor
Diff the live Linear team against the covenant. Writes nothing.
wand guard
The harness hook that blocks the ticket writes an agent may never make.
wand queue
Print the ranked, vetted Todo queue — what an agent may start next.
wand ticket
Print one ticket whole, for a reader with no context.
wand claim
Take one blessed issue — In Progress and assigned, before any work.
wand handback
Park one issue on a human — the question first, Needs Input second.
wand abandon
Hand one issue back to Backlog, with the evidence that undoes it.
wand file
File a finding into Triage, after searching for duplicates.
wand ui
Open the interactive interface — or render it to plain text.
wand version
Report the build and the covenant schema this binary speaks.
