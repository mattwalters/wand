title: Documentation
---

wand wires a repository to a [Linear](https://linear.app) team and runs an
opinionated software development lifecycle through it. These pages are the
two halves of that: the **doctrine** — what the lifecycle is and why each
rule in it exists — and the **reference** — what each command does, flag by
flag and exit code by exit code.

Read the covenant first if you are deciding whether wand's opinion is one
you want; read the command reference if you have already decided and need
to know what a verb does.

These docs are versioned with the tool. This site's root is the latest
build and tracks `main`; every release also publishes a frozen copy at
`/vX.Y.Z/`, so a repo pinned to wand vX.Y.Z can read the doctrine matching
its covenant schema. Pick the version in the header.
