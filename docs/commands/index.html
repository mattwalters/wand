Commands

Every command wand implements today, one page each. The pages are written from the command definitions, not from memory: flags, help text and exit codes match what the binary does.

There is no standalone bless page, because promoting a ticket is a human act with a human door: it lives in home, wand ui. A one-shot CLI verb that promoted a ticket to Todo would be a verb an agent could call, which is the whole thing the guard exists to prevent. wand pm bless is not that verb: it never sets a guarded status, only files a validated, human-reviewed proposal into Triage — the same status wand file already lands an agent’s own findings in — so it is documented on pm’s own page rather than getting one of its own.

Bare wand, with a terminal attached, opens that same home screen — it is what typing the tool’s name gets you. wand help is the documented way to get help instead; wand --help and -h work everywhere they always did. Without a terminal (a pipe, a script, CI), bare wand falls back to the same help wand help prints, rather than trying to open a program that needs one.

What every command shares

LINEAR_API_KEY. Everything that talks to Linear reads a full-access key from the environment, never from a file — a key in a checked-in file is a key in the repo forever. Create one in Linear’s security settings. wand version is the exception, along with wand ui --sample and wand ui --dump-screen, which render a built-in board, and wand stats, which reads only the local journal store.

The covenant file. A checked-in wand.toml parameterizes the covenant — status names, caps, commands. Absent one, the stock covenant applies. init, doctor and queue read it from the working directory; the lifecycle verbs walk up from the working directory to find it, so a verb run from a subdirectory sees the same covenant as one run at the root. Run the first three from the repo root.

Exit codes. Unless a page says otherwise, a command exits 0 on success and 1 on any failure, with the reason on stderr. Several commands say otherwise, and each of their codes is a contract something else depends on: guard (the harness hook), doctor (CI), file (a refusal to file a duplicate is a failure, on purpose), the orchestrators plan, pm and run, whose 0/2/3 tell a scheduler how a run ended — planned or converged (or proposed), handed back, or parked — leaving 1 for a run that never started; pm bless, whose own 0/1/3 mark a batched write rather than a single one — filed, refused before any write, or a write that failed partway through, reporting what had already landed; and dispatch, the selector over the orchestrators, whose 0–5 add locked, nothing-to-do and Linear-unreachable to that same vocabulary — a scheduler’s whole view of a pass is a status and a log.

wand init
Bootstrap a Linear team to the covenant and install the guard hook.
wand doctor
Diff the live Linear team against the covenant. Writes nothing.
wand guard
The harness hook that blocks the ticket writes an agent may never make.
wand queue
Print the ranked, vetted Todo queue — what an agent may start next.
wand ticket
Print one ticket whole, for a reader with no context.
wand claim
Take one blessed issue — In Progress and assigned, before any work.
wand handback
Park one issue on a human — the question first, Needs Input second.
wand abandon
Hand one issue back to Backlog, with the evidence that undoes it.
wand pm
Propose a set of tickets from a decided product brief, then bless the set into Triage.
wand file
File a finding into Triage, after searching for duplicates.
wand plan
Research one To Plan ticket into a plan a human can bless.
wand dispatch
Pick the one ticket to run next, and run it — the selector over the loop.
wand run
Own one ticket from claim to a terminal state — implement, CI, review, revise.
wand sweep
Act on one thing left over after a run ended — everything dispatch's loop does not see.
wand stats
Aggregate reports over the run journal — token velocity, per-harness x per-phase, convergence, and per-ticket totals.
wand ui
Home — three views, one job each, and the one place blessing happens.
wand version
Report the build and the covenant schema this binary speaks.
